# 운영체제의 기본 옵션에는 컨테이너가 있어요!

## 요약
대학원 연구하는 과정에서 RISC-V 실험을 위해 연구실 공유기를 여러 대를 분해했다.
그 과정에서 대부분의 임베디드 OS 기본 설정에 `chroot`가 포함돼 있음을 확인했다.
`chroot` 환경을 이용해 `공유기`와 `스마트폰`에 Ubuntu 컨테이너를 구동하고 딥러닝 모델을 실행하는 데 성공했다.
본 발표에서 `공유기`에 Ubuntu와 모델을 올리는 절차, 그리고 작동 원리를 상세히 설명할 예정이다.

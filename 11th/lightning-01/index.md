# Boot-Time Storage I/O 최적화를 통한 부팅 시간 단축

## 요약
시스템 부팅 과정에서는 커널, 서비스 실행 파일, 공유 라이브러리, 설정 파일 등 부팅에 필요한 다양한 데이터를 저장장치에서 읽습니다. 필요한 데이터가 Page Cache에 없다면 Storage I/O가 발생하며, 해당 데이터를 기다리는 작업이 부팅의 Critical Path에 포함된 경우 I/O 대기 시간이 전체 부팅 시간에 직접 반영됩니다.

따라서 Boot-Time Storage I/O 최적화의 최종 목적은 저장장치의 처리 성능 자체를 높이는 것이 아니라, 부팅에 필요한 데이터를 적절한 시점에 준비하고 Storage에서 읽어야 하는 데이터의 양을 줄여 Critical Path에서 발생하는 I/O 대기 시간을 최소화하는 것입니다.

해당 발표에서는 우선 부팅 과정에서 발생하는 Storage I/O의 특징을 살펴봅니다. 이후 Readahead 사이즈 조절을 통한 데이터 Preloading, 데이터가 실제로 접근되기 전에 Page Cache에 적재하는 Prefetch, 데이터 자체를 압축하여 읽어야 하는 데이터의 양을 줄이는 Compression을 소개합니다. 마지막으로 각 기법이 부팅 시간에 미치는 효과와 Storage I/O, Page Cache, 메모리 및 CPU 사용 사이의 trade-off를 간략하게 설명하고자 합니다.
